# Changelog

## 0.1.0 — experimental, prepared for initial publication

- Arinn suite with optional Ratataskr mail, Aring calendar and YggDrive storage.
- Independent home/storage Compose roles and common management commands.
- Plain-language architecture, deployment, license and recovery documentation.
- Source, calendar, mail and disposable container test automation.

This is an early source release. Exact parity with an existing installation,
automatic migration, physical two-host routing, live provider acceptance and
off-host restoration have not been established by the container sandbox.
No released tag or hosted Actions result is implied by this entry.
