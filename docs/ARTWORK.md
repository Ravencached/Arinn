# Artwork provenance and reuse

Recorded 2026-10-27. The project owner confirmed that the Ratataskr squirrel,
logo and knotwork illustrations, Aring logo and Ygg mascot were created for the
project using image generation, rather than downloaded from an external artist.
This is an owner-supplied provenance record; it is not an independent guarantee
of copyright, originality, exclusivity or trademark clearance.

All PNG and SVG artwork paths listed in `REUSE.toml` are offered under
**CC BY 4.0**, to the extent licensable rights are held. Attribution is to
**Selfhost Suite contributors**. Retain this record and indicate modifications.
No exclusive rights are asserted in generated material where such rights do
not exist. Existing license documents and third-party templates are excluded.

| Asset family | Source and derivatives |
|---|---|
| Ratataskr squirrel, logos and knotwork | `components/ratataskr/themes/ratataskr/images/`; project-created branding and decorative variants, including geometric SVG artwork |
| Aring logo and web icon | `components/aring/assets/logo.png` and `components/aring/web/icon.svg`; project branding |
| Aring Android icons/splashes | PNG files under `components/aring/android/app/src/main/res/`; resized/generated project variants; `scripts/android-artwork.ps1` records the bitmap resizing procedure |
| Ygg guardian PNG | `components/yggdrive/prototype/assets/ygg-guardian-v2.png`; generation prompt/date retained in `Ygg-character-prompt.md`; copy in Windows invitation assets |
| Ygg vector marks | SVG files in `components/yggdrive/prototype/` and Windows invitation assets; project-created vector branding |

The source archive does not include an external image-generation service or
model. Reusing the supplied images does not require that service. Re-creating
the exact original pixels from a prompt is not promised.

If future contributors add external artwork, record its source and permission
before including it. Do not assume this project-wide artwork policy changes a
third-party artist's existing terms.
